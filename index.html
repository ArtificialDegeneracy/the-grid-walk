How it works
The Model

XGBoost multinomial classifier trained on 2020–2025, ~8K driver-race rows. 16 features blending driver ELO, track-type history, qualifying, and team strength.

The Method

Walk-forward validation, no leakage. Every feature is computed using only data available before the race. Predictions are graded against real finishing order.

The Output

Win, Top-5, and Top-10 finish probabilities per driver, combined into Expected Points. Pick groups for Win, Top-3, Top-5, Top-10, Sleepers, and High-Risk. The whole field, ranked, every race.
